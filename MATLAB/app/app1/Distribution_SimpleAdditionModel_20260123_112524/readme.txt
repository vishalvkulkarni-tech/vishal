========================================
Dynamic Model GUI - SimpleAdditionModel
========================================

INSTALLATION:
1. Install MATLAB Runtime R2024b (FREE, no license needed)
   Download: https://www.mathworks.com/products/compiler/matlab-runtime.html

USAGE:
1. Double-click DynamicModelGUI.exe
2. Modify parameters in the GUI
3. Click "Run Simulation"
4. View results

FILES:
- DynamicModelGUI.exe : Main application (contains GUI + Model)
- README.txt : This file

REQUIREMENTS:
- Windows 10/11 (64-bit)
- MATLAB Runtime R2024b (FREE)
- NO MATLAB license required!
